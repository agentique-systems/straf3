# ONE WORLD, AND IT IS THE SHIPPED ONE
# ------------------------------------
# Every number here was produced in the world `straf3_map::compile` builds and
# `CompiledMap::collider()` hands over -- the same call `straf3-game`'s scene and
# `straf3-render` both go through. This probe has no second brush-to-hull
# derivation and does not depend on the `quake-map` parser at all; `map.collider()`
# at src/main.rs:175 is the only world it ever constructs, and every trace, every
# `step_in_place` and every gate sweep runs against it.
#
# That is a deliberate difference from `probes/coil-course`, which carries two
# worlds and says so: its H1-H5 use its own `Hull::from_planes` path and only its
# H6 uses the shipped compiler, because that probe's value is being an independent
# second derivation of the compile step. This one asks a different question --
# what does the course afford a player -- and a player runs in the compiled world.
# `compile_hull` adds the bevel planes a swept box needs, and a hull clearing a lip
# at 600 ups is exactly the case that is sensitive to them, so measuring anywhere
# else would have been measuring a course nobody plays.
#
# WHAT THIS FILE DOES NOT ESTABLISH
# ---------------------------------
# - No completing run. At the time of writing, no search has driven cleave from
#   the start line to the finish. The searcher's negatives are recorded in full
#   below, with their coverage, because a negative with no coverage numbers is
#   not a result. They are statements about this search, not about the map.
# - No branch times, and therefore no crossover speed. The map's headline
#   question -- at what entry speed does the leap start beating the sweep --
#   has no answer yet in any form.
# - No maximum deliverable speed at the launch lip. Section S3's gate is only a
#   gate if that number is near it, and it is unmeasured.
# - Nothing here was played by a human, by operator decision for this milestone.
#

== the searcher's negatives, recorded in full ==

Neither branch has been driven to the finish. Both runs below are NEGATIVE and
their coverage is printed because that is the only thing that makes a negative
readable. What defeats the searcher is worth stating precisely, because it is a
property of a greedy one-step hill climber and not of the map:

  Its objective is the hull's distance to the next goal volume, which is the
  right SHAPE -- the clock is satisfied by crossing a volume, not by arriving at
  a point -- but it descends that distance greedily. Cleave's slot is therefore
  a local minimum: from the launch lane, walking off the lip and INTO the slot
  reduces distance to the landing pad, and the pad's 160-unit south face is then
  a wall the search cannot climb. An earlier run sat there for 43 seconds of
  simulated time, circling, and reached 1437 ups doing it.

  Forbidding the slot (--forbid-box) is what a bypass hypothesis is for and it
  does force the flight, but each remaining local minimum -- the finish bail
  ramp, the chicane blocks -- has to be named the same way. That is per-map hand
  tuning of the measurement driver. It is legitimate here, where the driver is
  an instrument; it is exactly what r2's reusable agent may not need.
